# Slow Bloom

**Live site: https://codersdesk1-droid.github.io/slow-bloom/**

A cinematic, scroll-driven website for Slow Bloom, a concept coffee brand.

As you scroll, a coffee bean falls from the plant, roasts, drops into the grinder, and ends as espresso in the cup. Below the hero: the bloom test, how it works, the coffees, a no-traps promise, FAQ, and an order form.

Plain HTML, CSS, and JavaScript. No build step. Every push to `main` publishes to GitHub Pages automatically.

## Preview on your own computer (optional)

Only needed if you edit the files and want to look before pushing. In this folder, run:

```
npx http-server . -p 8080
```

While that command is running, open `http://localhost:8080` in a browser on the same computer. That address only works there, not for anyone else.

Slow Bloom is a fictional brand. No real coffee is sold and the order form places no orders.
