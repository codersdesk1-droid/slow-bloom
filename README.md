# Slow Bloom

A cinematic, scroll-driven website for Slow Bloom, a concept coffee brand.

As you scroll, a coffee bean falls from the plant, roasts, drops into the grinder, and ends as espresso in the cup. Below the hero: the bloom test, how it works, the coffees, a no-traps promise, FAQ, and an order form.

Plain HTML, CSS, and JavaScript. No build step.

## Preview locally

```
npx http-server . -p 8080
```

Then open http://localhost:8080. Opening `index.html` directly shows the still hero, because browsers limit some features on `file://` pages.

Slow Bloom is a fictional brand. No real coffee is sold and the order form places no orders.
